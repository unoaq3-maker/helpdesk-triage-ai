    Why the rules chose this

      This is optional. The demo works fully without it. The key is sent only from your browser to the endpoint you set, is not saved on a server, and should be a personal key you can revoke.

      Built by Mohammed Abbas as a learning-in-public project while preparing for IT support and service-desk roles in Bahrain. The logic is rule-based and visible on purpose: a first-line analyst should be able to explain a priority, not hide it in a model.

      Open this folder’s README.md for the story, what I learned, and how to host it for free on GitHub Pages. Nothing in this demo is a substitute for a live ITIL tool or a security playbook.
